# 🏔️ Mountain Name Recognition

A Natural Language Processing project for recognizing mountain names in English text using multiple Named Entity Recognition (NER) approaches.

---

# Project Overview

The goal of this project is to compare several approaches for recognizing mountain names in text and evaluate their strengths and weaknesses.

The project implements three different NER models:

* Dictionary-based NER
* Conditional Random Fields (CRF)
* BERT fine-tuning (Hugging Face Transformers)

An optional LLM-based judge is also included for prediction validation and comparison.

---

# Features

# Models

## Dictionary NER

A simple rule-based model that searches for mountain names using a predefined dictionary.

### Advantages

* Extremely fast
* No training required
* Very low memory usage

### Disadvantages

* Cannot generalize
* Misses unseen mountain names
* Sensitive to spelling variations

---

## CRF Model

Conditional Random Fields are statistical sequence models commonly used for Named Entity Recognition.

Features include:

* Current token
* Previous token
* Next token
* Capitalization
* Prefixes
* Suffixes

### Advantages

* Lightweight
* Fast inference
* Learns contextual patterns

### Disadvantages

* Manual feature engineering
* Lower performance than transformer models

---

## BERT Model

Fine-tuned DistilBERT token classification model using Hugging Face Transformers.

Tokenizer:

* DistilBERT Tokenizer

Architecture:

* DistilBERT Encoder
* Token Classification Head

Labels:

* O
* B-MOUNTAIN
* I-MOUNTAIN

### Advantages

* Best accuracy
* Understands context
* Handles unseen mountain names

### Disadvantages

* Slower inference
* Requires GPU for efficient training

---

## Local LLM Judge

Optional component used to review or validate predictions generated by other models.

# Dataset

The dataset is automatically collected from Wikidata using SPARQL queries.

Each example contains:

```json
{
    "tokens": [
        "Mount",
        "Everest",
        "is",
        "high"
    ],
    "labels": [
        "B-MOUNTAIN",
        "I-MOUNTAIN",
        "O",
        "O"
    ]
}
```

# Usage

## Download mountains

```bash
python scripts/scrape_mountains.py
```

---

## Create dataset

```bash
python scripts/create_dataset.py
```

---

## Train BERT model

```bash
python -m scripts.train_ner \
    --train data/final/train.json \
    --validation data/final/validation.json \
    --epochs 3 \
    --batch-size 8
```

---

## Predict

```bash
python -m scripts.predict_ner \
    --text "Matterhorn is located in Switzerland."
```

Example output:

```text
Matterhorn      B-MOUNTAIN
is              O
located         O
in              O
Switzerland     O
```
